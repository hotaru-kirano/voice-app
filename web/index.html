Voice commands
  • “Save note” or “new note”: save and start a fresh note. You can also end a sentence with “…save note”.
  • “Scratch that” or “undo”: remove the last thing you said
  • “Discard note”: clear the current note
  • “Read back”: read the current note aloud
  • “Stop listening”: turn the mic off
